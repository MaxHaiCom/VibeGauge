# VibeClean 🧠

专为 **Vibe Coding** 打造的极简 macOS 菜单栏轻量原生监控与清理工具。

> 深度解决在频繁使用 Claude CLI、Agy、Cursor 等 AI 编程工具时，死掉的 MCP 进程和残留开发服务越积越多、导致 Mac 内存耗尽卡死的问题。

---

## 核心特性

1. **常驻原生菜单栏（纯 Swift + AppKit）**：
   - 极简克制，自身开销极低（内存 <45MB，空闲 CPU 0.0%）。
   - 实时显示系统内存健康度（如 `● 61%`，绿/黄/红三色指示，基于 macOS 底层 `memory_pressure`）。
   - 一旦发现死掉的 MCP 孤儿进程，菜单栏即时动态提醒：`● 61% (9可清 670M)`。

2. **「四维画像甄别引擎」（0 误杀）**：
   - **亲缘拓扑**：严格锁定 `PPID == 1`（宿主终端已退出的孤儿进程）。
   - **通信协议**：检查是否监听本地端口，自动区分 **Web 开发服务器** 与 **无端口 MCP 工具**。
   - **特征签名**：识别 `mcp`、`_npx`、`apple-docs`、`chrome-devtools`、`xcodebuildmcp` 等工具链。
   - **白名单保护**：系统核心服务、正在运行的终端 CLI、本地常驻应用（如 `figma-agent-bridge`、Docker、Tailscale）受到永久保护。

3. **菜单功能**：
   - **📊 系统内存健康度**：物理内存占用、压缩内存池、Swap 使用量实时透视。
   - **🧹 一键清理孤儿 MCP**：点击立刻回收所有悬空 MCP 进程，秒级释放 500MB~2GB 内存。
   - **🌐 本地开发端口感知**：自动列出监听 `:3000`、`:5173`、`:8000` 等端口的 Node/Python 开发服务，支持针对特定端口单独执行停止。
   - **⏱️ 静默自动清理**：可勾选开启“每 30 分钟静默巡检”，发现孤儿自动回收并通过系统通知知会。
   - **🚀 开机自启**：支持随 macOS 系统启动常驻。

---

## 编译与启动

```bash
# 进入项目目录
cd ~/Desktop/code/vibe-clean

# 编译并打包 App
./build.sh

# 启动运行
open VibeClean.app
```

> **提示**：若你安装了 Bartender 6 或其他菜单栏管理工具，新加入的 VibeClean 图标可能会默认被收纳在折叠区，可在 Bartender 设置中将其拖至主菜单栏。
